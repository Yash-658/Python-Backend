FastAPI     - web framework that handles HTTP requests and serves your data to users.
   ↓
SQLAlchemy  - Python database toolkit / Object-Relational Mapper (ORM) that lets you write Python code instead of raw SQL queries.
   ↓
psycopg     - this driver handles postgresql specific communication
   ↓
PostgreSQL  - RDBMS for persistent storage

⭐ Pydantic : the data validation and serialization library that defines how data looks, 
ensuring incoming API requests and outgoing responses match your exact structure and rules.

⭐ Alembic is SQLAlchemy's database migration tool.
⭐ pwdlib provides a clean password-hashing interface, while Argon2 is the hashing algorithm we'll use.
⭐ PyJWT for handling JWT encoding and decoding 
⭐ HS256 for signing secret key for our JWT
⭐ Using OAuth2PasswordBearer for fetching JWT token from the authentication header of the request body~
⭐ Using RBAC (Role Based Access Control), ex: admins users can modify problems, while normal users can access and submit solutions on them, and anyone can see them~ 

IMP POINTS -
>> We do not decrypt the hash. Password hashes are designed to be one-way.
>> ID generation is handled by PostgreSQL itself
>> JWT = Header.Payload.Signature; payload is readable, while the SECRET_KEY creates a signature tied to the exact header+payload, 
preventing tampering(can't impersonate other users by modifying JWT) but not impersonation if the valid token is stolen.
>> JWTs are bearer tokens: possession of a valid, unexpired token grants access as that user.
